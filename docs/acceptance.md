# FuturePrice 安卓首版验收

本清单是真实购物 App 与真机的最终验收门槛，目前尚未完成。开发版的构建、合成多商品、权限与生命周期实测另见 [验证记录](verification.md)，不据此勾选真机验收。方案见 [首版计划](../README.md)。

## 环境与会话

- [ ] 记录机型、Android 与 App 版本、屏幕尺寸和字体缩放、构建和 SDK 版本，APK 可构建安装。
- [ ] 悬浮、使用情况访问授权与全屏共享确认后，在目标购物 App 能接收有效画面；拒绝必要授权显示未开启。
- [ ] 阶段 1 即检查三个目标 App 的截屏与悬浮限制；UsageStats 前台推断配合页面判断，未知、撤权或切换中停标，非支持页面帧及时丢弃。不得将此表述为仅采集购物 App。
- [ ] 当次会话跨已支持 App 无需逐个配置；新会话重新授权。
- [ ] 打包中文模型离线可运行；无 GMS 结论只限实测设备。
- [ ] 停止、撤权、锁屏、其他投屏抢占后释放资源、清空标签，迟到任务不能恢复。
- [ ] 黑帧、禁止悬浮或未知页面不保留旧值，不绕过保护。

## 商品与交互

- [ ] 多列、多商品分别对应，一个商品一个标签；默认 ¥100 →「10年≈150」，¥99.90 →「10年≈150」。
- [ ] 修改倍数后重算并改为自定情景说明，内部定点计算、展示整元。
- [ ] 划线价、月供、月销、优惠额、运费和总计不会冒充商品主价。
- [ ] 条件价格、区间、多 SKU 不确定时不猜；购物车只用该行明确小计。
- [ ] 标签避开源价和操作；无处放置计漏标，不从统计分母删去。
- [ ] 自有标签不触发价格递归计算或不断隐藏；非购物画面无商品误标。
- [ ] 滚动、切页、切 App、旋转及坐标变化先清空旧值；过期 OCR 不回流。
- [ ] 轮播与倒计时不会导致所有商品持续无标签。
- [ ] 商品点击、滑动、返回、规格选择、加购不受影响；不执行真实付款。
- [ ] 整窗不透明度符合系统规则；目标 App 自己阻止遮挡触摸时记录兼容失败，不禁用安全机制。
- [ ] 用户理解「10年≈金额」是情景值，能找到停止入口。

## 量化门槛

运行识别系统前，固定抽样规则、分母与门槛，冻结人工标注的正确商品与价格；不能事后剔除失败项目。

- [ ] 淘宝、京东、拼多多 × 列表、详情、购物车共九组，每组至少 10 个清晰完整商品，总计至少 100 个；按组报告。
- [ ] 各计划支持页型的固定验收集中，清晰完整无歧义商品 100% 正确标注；错值、重复或错商品关联均为失败。
- [ ] 另做至少 20 分钟未经挑选的连续浏览，使用获授权的测试账号或游客页面，由测试者当场核对并记录全部可见商品、正确、错误、缺失、歧义与半露出数量及原因，不录屏。无标签不算正确，清晰无歧义商品的错标或漏标同样阻止对应页型称已支持；无法当场确认的样本标为未验证，不补成通过。
- [ ] 至少 30 次滚动或页面变化；稳定页面至标签实际可见 P95 ≤1 秒。
- [ ] 页面变化至旧标签实际撤下 P95 ≤150 毫秒、最差 ≤300 毫秒，不只测 OCR 返回时间；切换到非购物 App 也适用。
- [ ] 连续 20 分钟无崩溃、服务异常终止、明显热节流或资源持续增长；记录实际可测热状态和内存数据。
- [ ] 功耗同机、固定亮度、相近内容与网络，开启/关闭各 20 分钟、两轮对照；报告局限，不将短时电量百分比当精确功耗。

## 隐私与交付

- [ ] 默认画面与 OCR 内容不落盘、不进入日志或网络；核对合并 Manifest、SDK 行为与联网观测。
- [ ] 不启用麦克风、摄像头、云模型或无障碍；使用情况访问仅用于本地支持 App 判断，不保存应用使用历史。
- [ ] 自动化用合成或获授权脱敏样本；真实页面设备内核对，仅保留汇总结果。
- [ ] 交付内部 APK、安装授权停止说明，以及逐 App、版本、页型覆盖报告。
- [ ] 用户能完成「开启 → 多商品分别显示 → 正常购物操作 → 停止」。

全部目标页型达标才称首版验收完成。只通过部分页面可以提供明确标记的试验版，不能替代原目标或宣称通用。

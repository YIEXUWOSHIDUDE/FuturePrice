# FuturePrice 验收清单

状态：全部待验证。文档、源码、macOS 测试和模拟器运行均不能替代真机验收。

## 1. 环境与完整链路

- [ ] 完整 Xcode 和 iOS SDK 可用，所用 API 经实际编译确认。
- [ ] App 和 Live Activity 扩展完成签名，安装到 iPhone 17 Pro / iOS 27.0.0。
- [ ] 开启购物模式并完成系统确认后，切换到其他 App 仍收到有效屏幕帧。
- [ ] 不启用麦克风、摄像头或录制文件也能持续处理画面。
- [ ] 真实画面金额经本地 OCR 和规则判断后，实际出现在灵动岛。
- [ ] 断网下可识别已显示的页面，画面与 OCR 文本不落盘、不上传、不进入日志。
- [ ] 排除自身提醒区域，¥160 不会被再次当作商品价格计算。

## 2. 金额与失效规则

- [ ] 明确实付款 ¥100 → ¥160；不用浮点误差产生错误的分位金额。
- [ ] 同时出现划线价 ¥129、优惠 ¥29、实付款 ¥100 时采用 ¥100。
- [ ] 仅明确单一商品价时标记“商品价”，不冒充实付款。
- [ ] 月供、优惠额、价格区间、多商品和不明确币种不被猜测为实付款。
- [ ] 快速滚动、切页或切 App 时撤下旧金额；迟到的 OCR 结果不能恢复旧值。
- [ ] 无价格、黑屏、采集中断或权限撤销时不保留有效金额假象。
- [ ] 停止购物模式后停止采集、识别和 Live Activity；晚到任务不能重新显示金额。

## 3. 体验测量

- [ ] 首轮至少连续使用 20 分钟、完成 30 次页面变化，记录测试 App 与版本。
- [ ] 分别测量稳定页面至实际显示的延迟、页面变化至旧值撤下的延迟，报告中位数、P95 和最差值。
- [ ] 暂定体验目标：稳定页面后实际显示 P95 ≤2 秒；这是验收候选目标，不是已达成承诺。
- [ ] 记录误读、漏读、歧义拒绝及失败场景，不把拒绝识别算作正确识别。
- [ ] 检查锁屏、返回前台、低电量模式、其他 Live Activity 共存和系统中断后的行为。
- [ ] 检查发热、耗电与内存增长，明确观察时长与限制。

## 4. 覆盖与交付

- [ ] 先在一个购物 App 打通商品页和结算页，再扩展淘宝、京东、拼多多、Amazon 等代表性 App。
- [ ] 按实际测试记录“App / 版本 / 页面 / 正确识别 / 拒绝 / 失败原因”，不声称全覆盖。
- [ ] 用户能实际安装并完成“开启 → 浏览 → 看到正确提醒 → 停止”的一次购物流程。

首个开发里程碑是第 1 节的真机完整链路。若后台处理或及时更新不成立，先重新评估方案，不以手动截图、分享或输入金额冒充原定体验。

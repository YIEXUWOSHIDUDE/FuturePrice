# 省钱提醒 Chrome 扩展（实验）

在**已手动启用**的购物网页上，在每个能确定主价的商品价格下方插入独立一行提醒「不买，10年后 ≈ $7」（橙色底，金额加粗放大；默认 1.5 倍，含本金的假设情景，不是折扣或收益承诺，鼠标悬停可看说明）。原生 JS、Manifest V3，无构建步骤、无远程代码、不联网。

## 安装

1. Chrome 打开 `chrome://extensions`，开启「开发者模式」。
2. 「加载已解压的扩展程序」，选择本目录 `chrome-extension/`。

## 演示

```sh
cd chrome-extension/demo
python3 -m http.server 8765
```

打开 `http://localhost:8765/`，点击扩展图标 →「在此网站开启」→ 在权限弹窗中允许。

预期：正例 A–G 各一条提醒（金额 A ¥150、B ¥120、C ¥299、D ¥75、E ¥192、F ¥90、G ¥1949），负例和正文金额没有标签；「改首价」后 A 变 152；插入/删除商品后标签随之增减；打开弹窗时被盖住的价格不显示标签；「加入购物车」可正常点击并计数。

注意：`http://localhost/*` 权限覆盖本机所有端口。

## 测试

```sh
node --test chrome-extension/test/rules.test.js chrome-extension/test/background.test.js chrome-extension/test/cart-totals.test.js
```

该命令覆盖 17 项基础规则、5 项购物车金额核对规则与 6 项后台权限/回退测试（后者模拟 Chrome API）。浏览器集成测试：安装 Playwright 与其 Chromium 后运行 `node chrome-extension/test/browser.cjs`，也可用 `PLAYWRIGHT_MODULE` 指定已有模块路径。测试使用隔离配置与 localhost 合成页，临时副本 manifest 预授予 localhost；交付 manifest 不变。因此不验证首次权限确认弹窗或可选权限撤回。

浏览器测试曾使用 Playwright 1.62.1 与其 Chromium。在仓库根目录准备测试依赖：

```sh
npm install --no-save --package-lock=false playwright@1.62.1
npx playwright install chromium
node chrome-extension/test/browser.cjs
```

也可通过 `PLAYWRIGHT_MODULE` 指定已有 Playwright 模块。`node_modules/` 与测试输出不进入 Git。14 个套件分别为 `browser`、`amazon`、`generic`、`detail`、`jd`、`buybox`、`cart`、`catalog-replay`、`search-replay`、`center-replay`、`rendered-prices`、`restart`、`cart-quantity`、`collapsible`，执行方式相同。套件名称代表样本结构，生产代码不按网站域名分支。

## 打包

在仓库根目录执行 `python3 scripts/package-chrome.py`，生成 `output/FuturePrice-Chrome-0.3.4.zip`。只含运行文件和本说明，不含测试、截图、浏览器配置或依赖。也可以直接从源码加载，无需打包。

## 权限与行为

- 固定权限：`storage`、`scripting`、`activeTab`。网站权限为可选，只在 popup 中点击开启时申请**当前网站**（`scheme://hostname/*`）。
- 0.3.3 将权限申请及后续启用交给后台完成，避免权限弹窗关闭 popup 时中断启用。
- 启用后为该站点注册持久内容脚本（导航、重启后继续生效）并立即注入当前页；内容脚本运行并回报状态后才显示开启成功。
- 停用：注销脚本、清除该站所有打开页面上的标签、撤回该站权限。外部撤权或浏览器重启后自动对齐。
- 倍数修改后已打开的页面自动更新。
- 不读取账号或 Cookie，不拦截网络，不上传任何内容。不接受网页 `postMessage` 控制。

## 识别规则与限制（0.3.4 通用路径，不按网站分支）

- **金额**：元素文字须恰为完整金额：`¥/￥金额`、`金额元`、`$/€/£金额`，或 `CNY/RMB/USD/EUR/GBP/HKD/CAD/AUD` 代码加金额。拆开的币种/整数/小数按 DOM 文本合并（含隐藏的小数点）。schema.org microdata 的可见纯数字须配有效 `priceCurrency`。保留页面显示的符号（`$` 不推断是哪国货币），只做同币种倍数换算、不换汇。不支持逗号作小数点（如 `1.299,00 €`）。
- **新增金额结构（0.3.2）**：整段 `Now $469.99` / `Sale price` / `售价` 等当前售价标签；显式 `US $`、`CA $`、`AU $`、`HK $` 保留其声明币种。实际 CSS 生成的币种符号配纯数字也可识别；币种、整数、小号两位分位拆成三个可见元素时可合并，同容器读屏副本如存在必须一致。
- **可见性**：读屏专用的重复文本（极小、裁切或 CSS 不可见）不作候选；`aria-hidden` 本身不代表不可见。同一价格的嵌套包装只取最深一层。
- **卡片**：schema.org Product 或少量通用卡片选择器；否则最近的紧凑祖先（含商品图与链接/按钮）；否则详情区：含唯一 h1 商品标题、标题到价格之间可见文字不超过 400 字且中间没有另起小节的可见标题（价格之后的规格、说明、评论长度不限），或（无 h1 时）只含一个 h2 且文字有限；两者都须有独立商品图/购买控件证据。没有 h1/h2 的详情页（如商品名只是普通 div/span）：区域内唯一的商品名元素（class/id 同时含 product/sku/goods/item 与 title/name，或 `itemprop=name`）在价格之前、标题到价格紧凑，并且附近（最多四层祖先）同时有大商品图和购买动作。购买动作可以是按钮/链接，也可以是可见短文本恰为「加入购物车 / 立即购买 / Add to cart / Buy now」等、且可点击（含 `cursor:pointer`）的普通元素。独立购买区（如详情页右栏）：价格最近的、渲染文字不超过 1500 字且含上述购买动作的祖先；商品标题与主图可以在兄弟列，但向上 12 层内须有只含一个 h1（或一个商品名元素）且有大商品图的公共祖先。
- 无链接的紧凑重复商品块可由同级图片与价格结构识别；含明确配送语义的单选项即使有图标也排除。横向 flex 中与价格同一行的 `You save` 仍参与上下文排除。
- **选项与重复价**：复选框/附加服务（如延保）里的金额排除；未选中的单选项、`<option>`、`aria-checked/aria-selected=false` 选项里的金额排除；已选选项里与主价相同的金额不造成歧义。多个有效价格金额完全一致时取一个（优先非选项价、带价格语义的元素）；金额不同仍不标。
- **购物车**：每行商品按卡片单独识别；行内若有数量控件（≥2）且两种金额满足「小计 = 单价 × 数量」，标该行小计；订单小计/合计/税（subtotal、total、tax、合计、小计）作为前缀时排除。支持带数量语义的输入框/下拉框/旋转按钮，以及有明确增量按钮的紧凑自定义步进器。商品行有移除按钮和明确数量时，用相邻购物车区域的商品小计核对“已显示行总价”与“单价 × 数量”，仅采用唯一匹配。不会把已证明的行总价再乘数量；未识别完整商品行、小计不匹配、折扣或多个解时，不展示不确定的多件行金额。最多 40 行、4096 个中间金额状态，超限放弃推断。仍不能保证等于含运费/税/附加服务的结算价。详情区内位于标题之后另一小节（h2–h6 之后）的金额不作主价。卡片向上搜索最多 32 层，文字量按渲染文字计算，忽略内联样式；图片宽高须至少 32px，小徽标不算商品图。没有卡片的金额（正文、无标题的侧栏重复价）不标。
- **主价**：每张卡片只标一个明确主价。排除划线价，以及紧邻前后缀表明的单价（`/count`、`/each`、per、每…）、区间、估价、原价/List/Was、起价、优惠券、订阅、会员、运费、分期/月供等（中英文）。前后缀不跨括号、不计入其它价格，所以主价旁边括号里的单价不会让主价被拒。隐藏的弹窗/模板子树不计入上下文，可见文本遍历有数量上限。前后缀限定在价格所在的「行」（最近的块级祖先，纯价格包装都算同一行；上下行的块不计入，脱离文档流的读屏文本跳过），并在「or / 或」处截断，下方的月供或信用卡优惠不会影响上方主价；信用卡/会员条件价（如「Prime member … Pay $449 upon approval for Visa」）会被排除。多个有效价格无法确定时不标。
- **显示方式（0.3.1）**：提醒是文档流内真实占高度的一行，插在价格所在「纯价格组」之后——从价格向上取最高的、不含标题/按钮/图片、渲染文字不超过 60 字的祖先，所以原价与旁边的单价仍在同一行，提醒在整行下面，不会插到含图片或标题的整个商品容器之后。价格组位于横向不换行 flex 行内时，向上至整行之后插入（有界且不越过卡片），避免和价格/按钮挤在同一行。窄卡片里文案可换成两行。每条提醒是独立的 closed Shadow DOM `<futureprice-hint>` 宿主，不移动或替换商家节点；按价格元素复用，不每次重建。表格行/列表等父元素下改为插在价格组内部末尾。
- 竖向 flex 卡片内无变换或纯水平居中的绝对定位价格行临时改为文档流定位，防止提醒与底部价格重叠；停用或移除提醒时恢复原定位。其它绝对定位布局仍可能不支持。
- 提醒造成固定高度 `overflow:hidden/clip` 祖先裁切时，有界调整该容器的 `min-height`；停用或该容器不再包含提醒时恢复原值。不改滚动区域及 overflow。`max-height:0` 的收起面板内不生成提醒，旧的最小高度会恢复，因此不会撑开商家的收起状态。
- 价格被弹窗/浮层盖住时提醒隐藏但保留占位（避免页面跳动），遮罩移除后恢复；价格不再渲染或被删除时提醒移除。
- 自身提醒从价格扫描、上下文文字、卡片文字量和 MutationObserver 中排除，不会识别自己的金额或形成重排循环。
- 重新检查时机：DOM 变化、选中/数量控件的 change/input 事件、滚动、窗口缩放、页面内图片/媒体加载完成或失败、字体加载完成、body 或已标注卡片尺寸变化。不使用定时轮询。
- 已知风险：插入商家 DOM 的兄弟节点可能与个别前端框架的重渲染冲突；卡片固定高度时提醒可能撑出卡片底部；卡片自身为不换行的横向 flex 且价格直接位于卡片内时，提醒仍可能出现在右侧。
- 不支持：跨域 iframe、closed shadow root 内的价格、图片中的价格。
- **验证状态（0.3.2）**：本轮真实 Chrome 验证 Walmart 冰箱、Best Buy 有货鼠标、eBay 详情与搜索、Amazon 搜索、天猫首页商品、拼多多列表。京东及 Allbirds 沿用 0.3.1 真实验收，本轮结构回归通过；不冒充已重新实测。Target 人机验证、淘宝安全拦截、拼多多详情登录未完成。Best Buy 无货 Rose 详情仍未标注；eBay 无货详情的显示价也不代表可支付。未测得市场覆盖率，不保证最终结算金额，详情显示价可能未含运费/税/资格优惠。完整记录见 [development.md](../development.md)。

接口依据：[Chrome 站点权限](https://developer.chrome.com/docs/extensions/develop/concepts/declare-permissions)、[动态内容脚本](https://developer.chrome.com/docs/extensions/reference/api/scripting)、[Playwright 扩展测试](https://playwright.dev/docs/chrome-extensions)。

### 0.3.4 修复与当前验收结论

0.3.3 的购物车金额与折叠区问题已关闭：Allbirds 数量 1→2→1 时 $105/$210 对应 $158/$315/$158；加入 $14 袜子后两个商品分别显示 $315 与 $21，总商品小计 $224；Target 两件行总价 $16 仍显示 $24，没有再次乘数量。推荐区收起后恢复 42px 高，原默认窗口即可看清购物车商品；无需扩大窗口。两站测试商品已清空，没有下单。

28 项单元测试及 14 组浏览器回归全部通过。浏览器套件见上方测试说明。新增测试包含自定义数量变化、混合单价/行总价、重复计算防护、小计不匹配、未识别完整购物车、折叠及重新展开。验收摘要见 [development.md](../development.md)，原始日志与真实截图仅保留在本机。当前建议小范围内测，尚未发布；不把这两个网站的购物车验收扩大为全站兼容或最终付款金额保证。
